# ChatGBt

Interactive web synth built with Tone.js featuring a 16-step sequencer, tempo control, swing, randomization, and per-track mute toggles with visual feedback.

## Getting started
1. Serve the files locally (for example, with Python's built-in server):
   ```bash
   python -m http.server 8000
   ```
2. Visit [http://localhost:8000](http://localhost:8000) in your browser.
3. Click **Start Audio** to enable sound, then press **Play** to start the sequencer. Use **Randomize** to fill patterns or **Clear** to reset.
4. Adjust **Swing** for groove and click the track-level **Mute** buttons to drop elements in and out during playback.
